# Production Alpine Environment Setup on CentOS 6 (KVM)

This guide documents the step-by-step procedure used to deploy and configure the persistent production Alpine Linux guest (`alpine-docker`) on the CentOS 6.10 host (`dragon.jobvolume.com`, Linux kernel `2.6.32-754.35.1.el6.x86_64`).

---

## 1. Environment & Architecture Overview

Because the CentOS 6 host kernel (2.6.32) cannot run modern container runtimes (such as modern Docker engines that require cgroups v1/v2, modern seccomp, and kernel 3.10+), the production environment was deployed as a lightweight, persistent **KVM Virtual Machine** running Alpine Linux 3.20 (Kernel 6.6+), with its service stack managed via OpenRC.

### System Specifications
* **Host OS:** CentOS 6.10 (Final) 64-bit, Kernel `2.6.32-754.35.1.el6.x86_64`
* **Guest OS:** Alpine Linux 3.20 (x86_64)
* **Virtualization:** QEMU/KVM via `libvirt`
* **Network Driver:** Intel `e1000` virtual NIC connected to host virtual bridge `virbr0`
* **Storage:** 20 GB QCOW2 virtual drive image at `/wp/kvm/images/alpine-docker.qcow2`
* **Service Stack:** Python 3, PostgreSQL 16, MariaDB (MySQL), Apache HTTPD (`apache2`)

---

## 2. Host Prerequisites & VM Provisioning

### 2.1 Disk Image Creation & ISO Staging
On the CentOS 6 host (`root@dragon`):

```bash
mkdir -p /wp/kvm/images /wp/kvm/iso
cd /wp/kvm/iso

# Download Alpine Standard x86_64 ISO
curl -LO [https://dl-cdn.alpinelinux.org/alpine/v3.20/releases/x86_64/alpine-standard-3.20.3-x86_64.iso](https://dl-cdn.alpinelinux.org/alpine/v3.20/releases/x86_64/alpine-standard-3.20.3-x86_64.iso)

# Create 20 GB sparse QCOW2 virtual disk
qemu-img create -f qcow2 /wp/kvm/images/alpine-docker.qcow2 20G
2.2 VM Domain Provisioning
Launch the initial domain using virt-install. Because CentOS 6's QEMU 0.12 does not support modern VirtIO 1.0 specifications needed by newer Linux kernels out of the box, the virtual network adapter is defined as model=e1000:

Bash
virt-install \
  --name alpine-docker \
  --ram 2048 \
  --vcpus 2 \
  --disk path=/wp/kvm/images/alpine-docker.qcow2,format=qcow2,bus=virtio \
  --cdrom /wp/kvm/iso/alpine-standard-3.20.3-x86_64.iso \
  --network network=default,model=e1000 \
  --graphics none \
  --os-type linux \
  --os-variant generic \
  --extra-args "console=ttyS0" \
  --console pty,target_type=serial
3. Host Firewall & Bridge Fixes (CentOS 6)
Older CentOS 6 KVM bridge setups suffer from two known packet drops with modern guests:

Zero UDP Checksum Drops: Hardware offload on virbr0 generates empty/zero UDP checksums that Alpine's kernel drops silently, breaking DHCP.

Empty FORWARD Chain: Default iptables drop policies break outbound guest NAT.

Execute the following on the CentOS 6 host:

Bash
# 1. Enable IPv4 routing
sysctl -w net.ipv4.ip_forward=1

# 2. Fix DHCP UDP checksums on packets leaving virbr0
iptables -t mangle -A POSTROUTING -p udp --dport 68 -j CHECKSUM --checksum-fill

# 3. Allow guest to access host services and gateway
iptables -I INPUT 1 -i virbr0 -j ACCEPT

# 4. Enable bidirectional forwarding between virbr0 and the WAN interface (e.g., em1)
iptables -I FORWARD 1 -i virbr0 -o em1 -j ACCEPT
iptables -I FORWARD 2 -i em1 -o virbr0 -m state --state RELATED,ESTABLISHED -j ACCEPT
iptables -I FORWARD 3 -i virbr0 -o virbr0 -j ACCEPT

# 5. Enable NAT masquerading for the VM subnet (192.168.122.0/24)
iptables -t nat -I POSTROUTING 1 -s 192.168.122.0/24 ! -d 192.168.122.0/24 -j MASQUERADE

# 6. Save iptables to survive reboots
service iptables save
4. Guest OS Installation (Alpine Linux 3.20)
Connect to the guest serial console:

Bash
virsh console alpine-docker
Log in as root (no initial password required on live ISO).

4.1 Temporary Network Configuration
To fetch packages during installation without relying on DHCP:

Bash
# 1. Load network driver and configure static interface
modprobe e1000
ifconfig eth0 192.168.122.50 netmask 255.255.255.0 up
route add default gw 192.168.122.1 eth0

# 2. Set resolver
echo "nameserver 8.8.8.8" > /etc/resolv.conf

# 3. Verify outbound WAN routing
ping -c 2 8.8.8.8
4.2 Run Disk Setup
Run the Alpine installer to partition, format, and copy the root system to persistent storage:

Bash
setup-alpine

Confirmation: Type y to erase disk and proceed.

4.3 Eject Media and Reboot
Once Installation is complete appears:

Bash
poweroff
From the CentOS 6 host:

Bash
# Eject installer ISO from guest CD-ROM
virsh change-media alpine-docker hdc --eject --config

# Start VM from permanent virtual disk
virsh start alpine-docker
virsh console alpine-docker
5. Software Stack Installation & Initialization
Log in to the newly booted Alpine system as root.

5.1 Enable Repositories & Install Packages
Bash
# Enable community repositories
sed -i 's/^#\(.*\/community\)/\1/' /etc/apk/repositories
apk update

# Install Python 3, PostgreSQL, MariaDB, and Apache HTTPD
apk add \
  bash \
  curl \
  python3 \
  py3-pip \
  postgresql \
  postgresql-contrib \
  postgresql-client \
  mariadb \
  mariadb-client \
  apache2 \
  apache2-utils
5.2 Initialize and Start PostgreSQL 16
Bash
# Initialize database cluster data directory
/etc/init.d/postgresql setup

# Enable automatic startup on boot and start daemon
rc-update add postgresql default
/etc/init.d/postgresql start
Verification:

Bash
su - postgres -c "psql -c 'SELECT version();'"
5.3 Initialize and Start MariaDB (MySQL)
Bash
# Initialize MySQL system tables
/etc/init.d/mariadb setup

# Enable automatic startup on boot and start daemon
rc-update add mariadb default
/etc/init.d/mariadb start

# Secure default MariaDB installation
mariadb-secure-installation
Verification:

Bash
mariadb -u root -p -e "SELECT VERSION();"
5.4 Configure and Start Apache HTTPD
Bash
# Set ServerName to suppress FQDN warning
echo "ServerName localhost" >> /etc/apache2/httpd.conf

# Enable automatic startup and start service
rc-update add apache2 default
/etc/init.d/apache2 start
Verification:

Bash
wget -qO- http://localhost
6. Host Port Forwarding (NAT to VM)
To expose the services running inside the Alpine guest (192.168.122.50) to external networks or the CentOS 6 host's public IP (208.68.95.178), run the following iptables forwarding rules on the CentOS 6 host:

Bash
# Forward Host:8080 -> Alpine Apache:80
iptables -t nat -A PREROUTING -p tcp -d 208.68.95.178 --dport 8080 -j DNAT --to-destination 192.168.122.50:80
iptables -I FORWARD 1 -p tcp -d 192.168.122.50 --dport 80 -j ACCEPT

# (Optional) Forward Host:5432 -> Alpine PostgreSQL:5432
iptables -t nat -A PREROUTING -p tcp -d 208.68.95.178 --dport 5432 -j DNAT --to-destination 192.168.122.50:5432
iptables -I FORWARD 1 -p tcp -d 192.168.122.50 --dport 5432 -j ACCEPT

# Save the active firewall rules
service iptables save
