Step 6: Expose Services to CentOS Host / External Network
Since the VM is on 192.168.122.50:

From the CentOS 6 host, you can query Apache immediately via curl [http://192.168.122.50](http://192.168.122.50) or connect to databases on ports 5432 (PostgreSQL) and 3306 (MariaDB).

If you want Apache or MySQL reachable from your physical public IP (208.68.95.178), forward the ports using iptables on the CentOS 6 host:

Bash
# Example: Forward host port 8080 to VM Apache port 80
iptables -t nat -A PREROUTING -p tcp -d 208.68.95.178 --dport 8080 -j DNAT --to-destination 192.168.122.50:80
iptables -I FORWARD 1 -p tcp -d 192.168.122.50 --dport 80 -j ACCEPT
